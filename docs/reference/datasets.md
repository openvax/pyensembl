# Dataset constructors

`EnsemblRelease` selects a numbered [Ensembl](https://ftp.ensembl.org/pub/)
annotation. `EnsemblAnnotation` selects an assembly and dated geneset from
[the new platform](../ensembl-platform.md). Both provide the shared
[Genome methods](genome.md).

::: pyensembl.EnsemblRelease
    options:
      inherited_members: false

::: pyensembl.EnsemblAnnotation
    options:
      inherited_members: false
