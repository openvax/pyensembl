    Dataset constructors¶

    EnsemblRelease selects numbered and dated Ensembl datasets, infers assemblies, and supports explicit assembly/provider choices. See assembly selection for examples, metadata, API discovery, and cache compatibility. Both it and custom Genome objects provide the shared Genome methods.

    EnsemblRelease ¶

    EnsemblRelease(release=MAX_ENSEMBL_RELEASE, species=None, server=ENSEMBL_FTP_SERVER, *, genome_fasta=None, genome_fasta_type='toplevel', genome_fasta_mask='none', download_genome_fasta=None, genome_fasta_path=None, assembly=None, assembly_accession=None, provider=None, include_alt=None, reference_name=None, cache_directory_path=None, reference_metadata=None, _resolved=None, _preserve_legacy=False)

    Bundles together the genomic annotation and sequence data associated with a particular release of the Ensembl database.

    A release is either numbered or an annotation date, e.g. EnsemblRelease("2026_04", species="human"). Assembly identity is inferred from verified metadata; assembly= can select or check a particular build, full name, or versioned accession. Existing reference labels and cache layouts remain independent of the new assembly metadata.

    release : int or str Numbered Ensembl release, e.g. 116, or an annotation date on the new Ensembl platform in YYYY_MM form, e.g. "2026_04".

    genome_fasta : True or path, optional Reference DNA for sequence(): True for Ensembl's DNA for this release (see genome_fasta_type and genome_fasta_mask), or a local plain or gzip FASTA. Nothing is downloaded until download_genome_fasta(), download(), or pyensembl install.

    verify_sources ¶

    verify_sources(check_remote=False)

    Check recorded annotation MD5s; optionally read upstream manifests.

    Returns one report per GTF/sequence source. Existing files without a checksum are unrecorded, not corrupt. This never repairs data or writes receipts. MD5 checks accidental changes, not authenticity.

    with_mirror ¶

    with_mirror(mirror, *, genome_fasta_path_or_url=None)

    Return a Genome using this release's filenames at a flat mirror.

    Use the same mirror when installing and reopening data. New mirror downloads have their own source identities and do not populate the canonical EnsemblRelease cache. This is also the constructor used by the CLI's --custom-mirror option.

    Parameters:

    Name Type Description Default
    mirror str or Path

    URL or directory containing the Ensembl filenames for this release.

    		 required
    genome_fasta_path_or_url str or Path

    Explicit reference DNA source. Otherwise mirror requested Ensembl DNA, or preserve a local DNA file attached to this release.

    		 None

    Returns:

    Type Description

    A source-explicit genome, usable across processes and in Varcode.

    available_releases ¶

    available_releases(species=None, *, assembly=None, assembly_accession=None, provider=None, include_alt=None, refresh=False)

    List metadata for the selected assembly's numbered and dated releases.

    Uses bundled metadata and existing directory listings without network or cache writes unless refresh=True. With no assembly selection, use the species' latest numbered assembly. Entries are grouped by kind for display; their list order does not imply a cross-platform chronology. latest marks the conservative, verified choice used by EnsemblRelease("latest"). Explicit provider/coverage options select the dated platform only.
